Hello, my name is Alberto Huerta Luna. I am a Computer Engineer and Senior Software Engineer with a strong background in C++, systems programming, graphics programming, development tools, and low-level software.

Throughout my professional career, I have worked on software ranging from desktop applications and engineering tools to graphics systems, runtime environments, compilers, binary translation technologies, embedded and automotive software, mainframe systems, and game technology.

C++ and Native Development

C++ has been one of the central technologies throughout my career.

I have worked with multiple generations of the language, including C++98/03, C++11, C++14, C++17, and C++20, and I am currently expanding my knowledge of C++23.

My experience covers development environments ranging from older MS-DOS toolchains to modern Windows and Linux systems, including:

  • Borland C++
  • Watcom C++
  • Microsoft Visual C++
  • MinGW
  • GCC
  • Clang

I have used C++ for application development, graphics programming, systems software, debugging tools, validation software, simulation environments, game engines, runtime components, and engineering tools.

I am particularly interested in native software where understanding what happens below the application layer matters: memory, ABI boundaries, runtime behavior, operating-system interfaces, compilers, graphics APIs, and hardware interaction.

Systems and Low-Level Programming

Part of my professional work has involved software operating close to the runtime and operating-system layers.

I have experience with C, C++, Assembly, and low-level programming, including development involving mainframe environments and interfaces between high-level applications and native runtime components.

I have worked with technologies and concepts involving:

  • Assembly language
  • Mainframe software development
  • Runtime systems
  • Native interfaces

  • Memory management

  • Binary translation
  • Binary emulation
  • Compiler-related technologies

I have also worked on native interfaces connecting Java applications with functionality implemented in C, C++, Assembly, and other low-level languages.

Some of my work has involved understanding the interaction between runtime environments and compiled code, including investigation of JVM execution, native interfaces, binary translation, and compiler/runtime behavior.
